# IAA Aqueous Solvation: CPMD and Electron-Density Analyses

## Description

This repository contains computational data supporting the manuscript entitled:

**"Aqueous Solvation and Hydrogen Bonding of Neutral Indole-3-Acetic Acid Investigated by Car–Parrinello Molecular Dynamics and Electron-Density Analyses"**

The study investigates the aqueous solvation of neutral indole-3-acetic acid (IAA) using Car–Parrinello molecular dynamics (CPMD), radial distribution functions (RDF), coordination analyses, RDF-derived potentials of mean force, and electron-density analyses based on QTAIM, RDG, and IRI.

## Repository Contents

- **01_CPMD_Simulation:** Original CPMD simulation files, including energy and trajectory data.
- **02_Figure_2_Energy_Temperature:** Data supporting the analysis of adiabaticity and temperature.
- **03_Figure_3_RDF:** Radial distribution function data for the H19, H22, and O13 hydration sites.
- **04_Figure_4_Coordination:** Time evolution of coordination and hydrogen-bond interactions.
- **05_Figure_5_PMF:** RDF-derived potentials of mean force.
- **06_Table_1_Geometry:** Average geometrical parameters obtained from the molecular dynamics trajectory.
- **07_Table_2_QTAIM:** Electron-density topological descriptors of selected IAA–water interactions.
- **08_Figures_6_7_8_RDG_IRI:** Reduced Density Gradient and Interaction Region Indicator analyses.

## Computational Methods

The molecular dynamics simulations were performed using the CPMD program package, version 4.3. Electronic-structure calculations and electron-density analyses were performed using Gaussian 16 and Multiwfn.

## Data Availability

The files in this repository provide computational data supporting the structural, dynamical, energetic, and electron-density analyses presented in the manuscript.
